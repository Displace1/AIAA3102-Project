# Dependencies for the SuperAgent.

# Versions are pinned to what the OFFICIAL task1/task2 runs actually recorded in
# their run_manifest.json:
#   Python 3.14.6, numpy 2.5.5, scikit-learn 1.9.1, joblib 1.6.0
# Those runs are the results in the report, so the report is only reproducible
# against these numbers. Verify with `python -m unittest discover -s tests`.
#
# The previous file pinned torch==2.11.0+cu128 / torchvision==0.26.0+cu128,
# which matches no machine this project ever ran on (the dev machine has
# torch 2.5.1+cpu, no CUDA device). That has been corrected below.
#
# `--extra-index-url` is kept so torchvision can be resolved from the PyTorch
# index, and the CUDA build is the default because the image adapters
# (resnet18 / mobilenet_v3) are the only consumers that benefit from a GPU.
# For a CPU-only box, or to keep the download small, install with:
#   pip install -r requirements.txt
#       --extra-index-url https://download.pytorch.org/whl/cpu
# and swap the two torch lines for `torch==2.15.0` / `torchvision==0.29.1`.
